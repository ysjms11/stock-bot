## 0. 결론 요약 (TL;DR)

1. **충돌의 정체는 1988년에 정식화된 고전** — 브레이커=convex(하락 시 축소, CPPI 계열), 발사=concave(하락 시 매수, constant-mix 계열). 동시 수행 불가, 우열은 시장이 추세장이냐 반전장이냐에 갈림 (Perold & Sharpe 1988).
2. **"리스크 레이어가 전략 신호에 우선한다"는 사전식(lexicographic) 우위는 규제·업계 표준** — 유지해야 한다 (SEC 15c3-5, FIA 표준: 전략이 리스크 컨트롤을 오버라이드 불가).
3. **그러나 리스크 레이어의 '표현'이 이진 차단인 것은 이론·실무 모두 반박** — 이론 최적은 쿠션 비례 연속 감속(Grossman-Zhou 1993; Hsieh-Barmish 2017; Nystrup-Boyd 2019 실증), 기관 실무도 계단식 축소(멀티매니저 -5% 반감 → -7.5% 종료; 정지는 최후단).
4. **권고: "쿠션 발사" 규칙** — 드로다운 우위는 유지하되, -7%에서 발사를 0으로 만드는 대신 쿠션 비례로 사이즈를 연속 축소. 알파 초과손실(시장 대비)은 별도 하드 트리거로 분리. 하드 정지 도달 시 자동이 아닌 운영자 에스컬레이션.

## 1. 충돌의 이론적 정체 (Q1·Q2)

**Perold & Sharpe (1988, *Financial Analysts Journal* 44(1))** — 동적 자산배분의 고전적 이분법:
- **CPPI(convex)**: 하락 시 매도. exposure = m×(assets−floor). 봇의 -7% 브레이커는 **m=∞인 CPPI의 퇴화형**(한도 도달 시 위험노출 0).
- **Constant-mix(concave)**: 하락 시 매수 = 봇의 발사 철학.
- 우위 조건: convex는 추세 지속장, concave는 변동성 큰 반전장. **어느 쪽이 옳은가는 취향이 아니라 시장 성질에 대한 조건부 베팅** → 조건부 스위칭(레짐 게이트)의 이론 근거. [다중 출처 교차확인]

**Grossman & Zhou (1993, *Mathematical Finance* 3(3))**: 드로다운 플로어 하 최적 배분 = **위험자산 ∝ 쿠션(surplus)** — 한도 접근 시 매끄럽게 0으로 수렴하는 연속 감속이지 하드 스톱이 아님. ⚠️ Klass & Nowicki (2005, *Stat. Prob. Letters*): 이산시간 이식 시 최적성 보증 깨짐 → 계수는 보수적으로. [교차확인]

**Hsieh & Barmish (2017, arXiv:1710.01503)** ★수학적 기둥 — 적대검증 후 정밀화:
- 원문 Lemma(iff): 매 기 총 익스포저 I(k)가 밴드 `−M(k)V(k)/X_max ≤ I(k) ≤ M(k)V(k)/|X_min|` (M(k)=(d_max−d(k))/(1−d(k))) 안에 있는 것이 드로다운 ≤ d_max **확률 1 보증의 필요충분조건**. i.i.d. 불요(유계 수익률만).
- **이진 차단(쿠션 잔존 시 풀사이즈→한도 시 0)은 필요조건 위반으로 보증 불가** — "비례 축소가 이진 차단보다 낫다"의 수학적 근거. [원문 전문 정독·검증]
- ⚠️ 검증에서 잡힌 조건: (i) γ는 최악 단일기간 손실 역수로 캡 필수, (ii) 갭이 가정 하한 뚫으면 보증 무효, (iii) 레마는 **총 익스포저**(보유분 매도 포함) 규율 — "신규매수만 비례 축소"는 레마의 보증 밖 **휴리스틱**임 (방향 영감만 유효).

**Nystrup, Boyd, Lindström & Madsen (2019, *Annals of OR* 282)** ★유일한 레짐+드로다운 명시 합성 선례 — 원문 27p 전문 검증·확정:
- 메커니즘: `γ_t = γ_0 · D^max/(D^max − D_t)` — 실현 드로다운이 한도에 접근할수록 리스크회피가 쌍곡선형 발산. min()도 중재 규칙도 없이 단일 목적함수 안에서 **쿠션 넉넉→레짐(수익 예측)이 지배, 한도 근처→드로다운이 점근적으로 항상 승리**.
- 실증(OOS 18년, 10개 자산군 지수): MDD 0.19→**0.10** (절반), Sharpe 1.01→1.00 (사실상 무손실), Calmar 0.65→1.07. 단 초과수익 200bp 양보.
- 저자 경고: "한도에 너무 가까워지면 탈출 불가(trapped) — 한도 재설정 아니면 해고" = cash-lock 함정의 정식 인정. soft limit(γ₀≥3 필요), 연속 거래 전제(리밸런싱 주기 낮추면 열화).

**대안 한도 지표**: Goldberg & Mahmoud (2016, CED — 꼬리평균 드로다운), Chekhlov-Uryasev-Zabarankin (2003/05, CDaR) — 단일 실현값 대신 분포 기반. 봇 단순성 철학상 참고만.

## 2. 브레이커의 전제 검증 (Q2·Q3)

**van Hemert et al. (2020, *JPM* 46(8) "Drawdowns")** [원문 정독, 2개 에이전트 독립 확인]:
- 건강한 전략(Sharpe 0.5)도 10년 내 -2σ(-20%) 드로다운 확률 **43%** — 드로다운은 고장의 강한 증거가 아님.
- **드로다운 후 디리스킹이 기대수익을 지키려면 수익률에 양(+)의 자기상관(하락 지속성)이 있어야 함** — i.i.d.거나 평균회귀면 브레이커는 기대수익만 깎음. → **봇 DB로 검증 가능한 전제** (KR 지수·포트 수익률의 단기 자기상관 부호).
- "drawdown rules = poor man's volatility scaling."

**Kaminski & Lo (2014, *J. Financial Markets*)**: 스톱룰의 가치는 국면(자기상관 부호)에 조건부 — 모멘텀 국면 이득, 평균회귀 국면 손실. [교차확인]

**Bailey & López de Prado ("Triple Penance", *J. of Risk* 18(2))** [원문 정독·적대검증]:
- 확정: 스톱아웃 = "성과가 스킬 가정과 일치한다"는 귀무가설의 기각 검정. 자기상관 무시 시 하방 잠재손실(MaxQL·TuW) 최대 ~70% 과소평가.
- ⚠️ 검증 교정: 논문 기준은 **전략 자체의 절대 P&L 분포**다. "시장 기인 손실 면책"은 이 논문에 없음 — 벤치마크 상대화의 근거는 **기관 실무**에서 가져와야 함(아래).

**행동재무 (물타기 금지의 층위)**: Odean 1998·Staw 1976·Coval-Shumway 2005·Locke-Mann 2005 — 전부 **종목 단위·재량 판단** 맥락. 지수 레벨 자동 룰과 다른 층위. 틸트 방지 근거는 봇에선 절반 소멸(단 운영자 틸트 + 모델고장 감지 기능은 잔존).

**베타/알파 구분의 실무 형태** [핵심 발견]:
- 절대 하드스톱의 본고장(멀티매니저 포드)은 **시장중립 환경** — 업계 정당화는 "시장중립→고레버리지 허용→신속 삭감 필수"(레버리지 논리)+행동 규율. 롱온리 봇에 절대 스톱 직수입은 전제 불일치. [2차 출처 다수 일관, 1차 미확인 — 통설로 취급]
- 롱온리 기관 위임계약의 트리거는 절대손실이 아니라 **벤치마크 상대 성과** (SJCERA·Texas PRB IPS 실물) — 베타 손실 면책, 알파 손실 제재의 제도화 형태.
- ⚠️ "베타 기인이면 브레이커 완화"라는 **문자 그대로의 성문 규칙은 어디에도 없음** — 실무는 ①상대 트리거 ②베타 사전제거 ③추세 조건부 ④배분 밴드로 우회. 우리 설계는 표준 부품의 신규 조합이 됨.

## 3. 반대편 증거 (정직 보고)

- **기계적 바닥매수의 위험**: Rattray-Granger-Harvey-van Hemert (2020, *JPM* "Strategic Rebalancing") [원문 정독×2] — 월간 리밸런싱(=하락 시 매수)은 2007-09에 buy-and-hold보다 MDD **1.2배(5%p) 악화**. 완화책: 하락 추세 중 리밸런싱 지연(+2~3%p). Granger et al. (2014): 역발상 매수 = 숏 스트래들 동형. → **발사에 추세/레짐 게이트 필수 — v2 방향게이트(ma_dist<0)가 정확히 이 역할을 이미 수행.**
- **하드 디리스킹의 증폭 실패**: 1987 포트폴리오 인슈어런스(선물 매도 ~40%, Fed FEDS 2007-13 [원문]), 2020-03 vol-targeting 강제 디레버리징(ECB FSR [원문]) — 단 AQR(Asness 2018)의 규모 반론도 존재. 1인 봇은 시장 증폭과 무관하므로 이 축은 참고만.
- **변동성 관리 논쟁 양면**: Moreira-Muir (2017, *JoF*) "고변동성 시 축소가 알파" vs Man AHL (Harvey et al. 2018) "vol targeting이 좌측꼬리 절단+모멘텀 정렬" vs Cederburg et al. (2020, *JFE*) [원문] "OOS 실시간 구현 시 초과성과 소멸". → 변동성 단독 신호는 취약, **방향 게이트와의 결합이 봇 규칙의 생존 조건** (v2와 정합).
- **dry-powder 기회비용**: HSBC [원문]·Vanguard·AQR "Hold the Dip" — 현금 대기는 평균적으로 순비용(대기 12개월 +2% vs 즉시 +10%). 발사 철학의 보험료를 인정할 것. 예외(분할 우위)는 "최악 하방 시나리오"뿐 → 폭락 확인 후엔 일괄~소분할이 문헌 기본값.
- **KOSPI 특수성**: 2000년 이후 일간 -8%+ 급락 7회 중 6회 V자(90일 +15.3%), 유일 실패 = 2008 침체형 [유안타 2026-06 보고서, 단일 출처] — 쇼크형엔 발사 우호, 침체·시스템형이 실패 모드.

## 5. 권고: "쿠션 발사(Cushion Fire)" 중재 규칙 (Q5)

**설계 원칙**: ① 사전식 우위 유지 — 드로다운 레이어가 최종 결정권, 레짐은 오버라이드 불가 (SEC/FIA). ② 단 그 표현은 이진 차단이 아닌 연속 감속 (GZ/H-B/N-B). ③ 알파 손실과 베타 손실은 다른 문 (기관 상대 트리거). ④ 하드 정지 재개는 자동이 아닌 운영자 게이트 (FSB 에스컬레이션 + Fed "경직성이 신뢰성의 원천" + 오버라이드 빈도 자체를 감사).

```python
# 의사코드 — 월간 드로다운 브레이커 v2 (쿠션 발사)
D_SOFT = -7.0    # 현행 한도 유지: 여기서부터 감속 시작
D_HARD = -12.0   # 완전 정지 + 운영자 에스컬레이션 (월간; 2008-10 KOSPI -23% 대비)
ALPHA_EXCESS_LIMIT = -5.0  # 시장(KOSPI) 대비 초과 드로다운 한도 — 전략고장 검출

def buy_multiplier(port_dd_m, kospi_dd_m, regime):
    # 1) 알파 초과손실 = 전략 고장 의심 → 원인 불문 하드 정지 (재개=운영자 수동)
    excess = port_dd_m - kospi_dd_m          # 예: 포트 -10%, 시장 -3% → 초과 -7%p
    if excess <= ALPHA_EXCESS_LIMIT:
        notify_operator("ALPHA_BREACH", excess)   # 텔레그램 에스컬레이션
        return 0.0                                 # 수동 재개 전까지 모든 신규매수 0
    # 2) 쿠션 비례 감속 (베타 손실 구간): -7%까지 풀사이즈, -7%~-12% 선형 감속, -12% 정지
    if port_dd_m <= D_HARD:
        notify_operator("HARD_STOP", port_dd_m)
        return 0.0
    m = min(1.0, (port_dd_m - D_HARD) / (D_SOFT - D_HARD))  # -7%→1.0, -9.5%→0.5, -12%→0
    # 3) 레짐 🔴 발사는 m을 곱해 집행 (오버라이드 없음). 🔴 디바운스(3일)+v2 방향게이트가
    #    Strategic Rebalancing의 "추세 중 매수 지연" 요건을 이미 충족.
    #    발사는 2~3 트랜치 분할 (Vanguard: 최악 시나리오 방어 겸).
    return m
```

**동작 예시** (7/16류 사고 재현): 시장 -8%·포트 -9% (베타 폭락) → 초과 -1%p(정상), m=(−9+12)/5=0.6 → **🔴 발사를 60% 사이즈로 허용**. vs 시장 -1%·포트 -8%(알파 출혈) → 초과 -7%p → **정지+에스컬레이션**. vs 포트 -13% (2008급) → 정지+에스컬레이션(운영자가 판단).

**대안(더 단순)**: 시장 동반 조항 한 줄 — "KOSPI 월간 -7% 이하 동반 시 브레이커는 정지 대신 사이즈 반감". 이론 순도는 낮지만 §6 단순성에 최적. (멀티매니저 -5% 반감의 직계)

**구현 전 검증 항목** (van Hemert 전제): KR 지수·포트 수익률의 단기 자기상관 부호를 봇 DB(daily_snapshot)로 실측 → 양(+)이면 감속 구간을 더 보수적으로, 음(-)이면 D_HARD를 낮춰도 됨. + 쿠션 규칙 vs 현행 이진 규칙의 KOSPI 역사 시뮬(레짐 백테스트 스크립트 확장으로 가능).
